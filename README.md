# Proyecto Integrador: Análisis de Restaurantes (Zomato)

## Descripción
Este proyecto analiza un dataset de más de 9,500 restaurantes registrados en Zomato para evaluar patrones de ubicación, precios, disponibilidad de servicios y calificaciones de usuarios.

## Pasos Realizados
1. **Limpieza de Datos:**
   - Verificación y eliminación de registros duplicados.
   - Trato de valores nulos en la columna `Cuisines` e inspección de consistencia de tipos de datos.
2. **Cálculo de KPIs:**
   - **Total de Restaurantes:** 9,551
   - **Calificación Promedio Global:** 2.67 / 5.0
   - **Costo Promedio (2 Personas):** $1,199.21
   - **Porcentaje con Online Delivery:** 25.7%
   - **Porcentaje con Reserva de Mesa:** 12.1%
3. **Visualizaciones:**
   - Top 10 ciudades con mayor presencia de restaurantes.
   - Distribución cualitativa de calificaciones registradas.
   - Comparativo de calificación promedio entre restaurantes con y sin servicio a domicilio.

## Tecnologías Utilizadas
- Python 3
- Pandas & NumPy
- Matplotlib
